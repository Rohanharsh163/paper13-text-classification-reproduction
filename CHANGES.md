# Changes, 11 Nov (presentation cleanup)

The model implementations (ENC, MLM, AR, AR_pseudo), the training procedure and every hyperparameter are
**unchanged**. Their differences from the paper and the released code are documented instead (README, slides,
VIVA_PREP). All original results are kept, unchanged, in `archive/v1_nov1/`.

## Evaluation fixes

1. **Noise robustness now compares like with like.** Before, the relative F1 loss divided noisy F1 on the first
   500 test examples by clean F1 on all 1,000. `repro.py` now also stores `wf1_500` (clean F1 on the same 500), and
   all relative losses use it. This adds one evaluation call; it does not touch training or any random number
   stream, so all other stored metrics are identical to before.
2. **`aggregate.py` reads only `results/agnews.jsonl` and `results/sst2.jsonl`.** Previously it read every `.jsonl`
   in `results/`, so the smoke-test files would have been mixed into the tables on the next run. It now also stops
   if a row lacks `wf1_500` or if a cell has a repeated seed. The two stray files (`test_run.jsonl`,
   `sst2_test_fixed.jsonl`) were moved to `archive/v1_nov1/results/`.

## Reruns

3. **SST-2 rerun on the official split** (6,920 / 872 / 1,821, checked for overlaps). The 1 Nov SST-2 results were on
   a test set that merged dev and test; they are archived and replaced.
4. **AG News rerun**, needed to record `wf1_500` for every run. Every previously stored AG News number (F1, ECE,
   drop30, sub30, all 48 runs) was reproduced exactly, which also confirms the runs are deterministic.

## Figures, docs, slides

5. `make_figs.py` added (the original plotting script was not in the folder). End-of-line labels no longer overlap
   each other or the "chance" label; the noise chart uses the same-500 basis and shows seed spread.
6. README: consistent demo timing; live demo moved to n = 2,048 with expected output and a fallback file;
   AR/MLM/AR_pseudo differences from the paper and code; SST-2 protocol note (the paper scores SST-2 on the 872-example
   dev set); new folder map.
7. VIVA_PREP: numbers regenerated from the new results; Q1 (the 2,835 count includes 7 training sizes), Q6 (what
   did and did not reproduce, and why "AR beats ENC" is not the paper's two-regimes shape), Q13 (test-split
   validation and text/code mismatches in the released code); three new questions (AR_pseudo near chance, MLM and
   dropped tokens, vocabulary built from all training texts).
8. AUDIT: status note at the top (what was decided, what was fixed).
9. Slides added: `slides/Paper13_slides.pptx` and `.pdf`, generated by `slides/build_deck.js`, which reads every
   reported number from `results/`.
10. `demo/expected_output_n2048.txt`: captured output of the live-demo command, as a fallback.
